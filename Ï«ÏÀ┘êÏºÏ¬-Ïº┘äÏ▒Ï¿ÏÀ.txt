ربط موقع كنز بمحركات البحث - الخطوات بالظبط
============================================

الملفات دي بتتحط في ريبو ibra8y3-web/kanz في الأماكن دي:

1) الملف 0503cdb4f756605d6d3f28c2b0b03b44.txt  → جوه فولدر  docs/
2) الملف indexnow.py                           → جوه فولدر  crawler/
3) الملف indexnow.yml                          → جوه فولدر  .github/workflows/

من الموبايل: افتح الريبو على GitHub → ادخل الفولدر المطلوب →
Add file → Upload files → ارفع الملف. كرر للتلاتة.

--------------------------------------------
الجزء الأول: الفهرسة الفورية (بينج + 6 محركات تانية)
--------------------------------------------
بروتوكول IndexNow بيبلغ Bing وYandex وNaver وSeznam وYep
وأرشيف الإنترنت بأي صفحة جديدة أو متعدلة خلال ثواني.

1. ارفع التلاتة ملفات زي ما فوق.
2. شغّل البعت الأول لكل الصفحات (مرة واحدة بس):
   Actions → indexnow → Run workflow → فعّل خيار all → Run.
   كده الـ 11,431 صفحة هيتبعتوا كلهم فورا.
3. خلاص. من دلوقتي كل تحديث للكتالوج (كل 30 دقيقة)
   الصفحات الجديدة والمتعدلة بتتبعت لوحدها أوتوماتيك.
4. للمتابعة: سجّل في Bing Webmaster Tools على
   https://www.bing.com/webmasters واعمل Import from
   Google Search Console بعد ما تعمل الجزء التاني.
   من هناك هتشوف الصفحات وهي بتتفهرس.

--------------------------------------------
الجزء التاني: جوجل (بصراحة كاملة)
--------------------------------------------
جوجل مش مشتركة في IndexNow، ومفيش أي طريقة فورية لموقع زي ده.
اللي ينفع فعلا:

1. افتح https://search.google.com/search-console بحساب جوجل بتاعك.
2. Add property → URL prefix → اكتب:
   https://ibra8y3-web.github.io/kanz/
3. اختار التأكيد بملف HTML. جوجل هيديك ملف اسمه google....html
   نزّله وارفعه جوه فولدر docs/ في الريبو، استنى دقيقة، اضغط Verify.
4. من قايمة Sitemaps اكتب  sitemap.xml  واضغط Submit.
   (الملف سليم واتفحص: 11,431 رابط وXML صحيح، وrobots.txt عندك
   مظبوط ومشاور عليه.)
5. ممكن تلاقي "Couldn't fetch" جنب الـ sitemap: دي مشكلة معروفة
   عند ناس كتير مع مواقع github.io تحديدا. لو حصلت واستمرت:
   - جرّب Resubmit كل كام يوم.
   - اطلب فهرسة يدوية لأهم الصفحات من URL Inspection →
     Request Indexing (في حد يومي، فخليها للصفحات المهمة).
   - الحل الجذري: دومين خاص بيك (حوالي 10$ في السنة) مربوط
     بنفس الريبو. بيحل مشكلة الـ sitemap خالص وشكله أحسن للناس.

توقعات واقعية: مع sitemap سليم وتواريخ lastmod (موجودة عندك)،
جوجل بيفهرس موقع جديد زي ده خلال أيام لأسابيع، والـ 11 ألف
صفحة مش هيدخلوا مرة واحدة مهما عملت. مفيش خدمة ولا API
بتفهرس جوجل فورا لنوع المحتوى ده - الـ Indexing API بتاع جوجل
لصفحات الوظايف والبث المباشر بس.

--------------------------------------------
ملاحظات صغيرة
--------------------------------------------
- في حوالي 990 صفحة في sitemap.xml من غير تاريخ lastmod.
  مش مشكلة، بس لو المولّد ضاف التاريخ لكل صفحة هيبقى أحسن لجوجل.
- لو حبيت تغيّر مفتاح IndexNow يوم ما: غيّر اسم ملف المفتاح
  ومحتواه ونفس الاسم جوه crawler/indexnow.py (سطر KEY_NAME).
- نفس الخطوات دي تنفع لأي موقع تاني ليك: ملف مفتاح + الوركفلو
  + Search Console.
