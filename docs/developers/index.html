واجهة المطورين (API مفتوحة)

بيانات المتجر كلها متاحة كملفات JSON ثابتة، قراءة بس، من غير مفتاح ولا تسجيل. أي برنامج يقدر يسحبها ويدمجها. الملفات بتتحدّث مع كل تشغيل للمحرك (حوالي كل 30 دقيقة). مفيش حد رسمي للاستخدام، بس اطلب بحساب (cache) وما تعملش طلبات كتير ورا بعض: الاستضافة على GitHub Pages.

  • api/v1/index.json: فهرس كل التطبيقات (10201) بحقول مختصرة.
  • api/v1/apps/<slug>.json: سجل كامل لتطبيق، بكل النسخ المعروفة والبصمات.
  • api/v1/schema.json: وصف الحقول (JSON Schema).
  • sitemap.xml · app.json (نسخة تطبيق كنز).

الروابط ثابتة (v1). لو الشكل اتغيّر بشكل يكسر التوافق هيبقى v2 ومعاه v1 شغّال لفترة. دعم CORS: GitHub Pages بيرجّع Access-Control-Allow-Origin: * للملفات الثابتة، فالمتصفح يقدر يقرأها مباشرة.

curl -s https://ibra8y3-web.github.io/kanz-catalog/api/v1/index.json | jq '.apps[0]'
curl -s https://ibra8y3-web.github.io/kanz-catalog/api/v1/apps/<slug>.json | jq '.versions[0]'

الـslug = اسم التطبيق بحروف صغيرة وشرطات + أول 6 حروف من SHA-1 للمعرّف (موجود في كل سجل في الفهرس).

الترخيص والبصمة: كل تطبيق عنده حقل license (معرّف SPDX أو null لو غير معلن) وsha256 للنسخ. التطبيقات من نوع live بتتفحص آليًا في كل تشغيل؛ baked من لقطة ثابتة وبياناتها قد تكون أقدم.

إضافة بيانات ودمجها

  • لإضافة تطبيق: افتح Issue بنموذج «إضافة تطبيق إلى كنز» في المستودع، والمحرك بيفحصه (ترخيص مفتوح + APK + SHA-256) ويضيفه تلقائيًا. مستودعات GitHub بس.
  • للدمج في نظامك: اسحب index.json دوريًا وقارن latest_version وupdated. ملفات data/ و docs/ في المستودع بتتولد من المحرك وأي تعديل يدوي عليها بيتكتب فوقه، فالمساهمة بتتم عن طريق نموذج الإضافة أو بفتح Issue/PR على كود المحرك (crawler/).

Developer API (open, read-only)

The whole catalog is published as static JSON. No API key or sign-up is needed for read access: the store is open source, so there is nothing to protect. Files refresh on every crawler run (about every 30 minutes). There is no official rate limit, but cache responses and be gentle: it is hosted on GitHub Pages.

  • GET api/v1/index.json: slim index of all 10201 apps.
  • GET api/v1/apps/{slug}.json: full record with every known version and SHA-256.
  • GET api/v1/schema.json: JSON Schema.

URLs are stable under /v1/. Breaking changes will ship as /v2/. GitHub Pages serves static files with permissive CORS headers, so browsers can read them directly. Each record has kind: live (checked by the crawler each run) or baked (static snapshot, may be older). license is an SPDX id or null if undeclared.

To add an app, open an issue with the "Submit an app to Kanz" form (GitHub repos only). To merge the data into your own system, poll index.json and compare latest_version/updated. Files in data/ and docs/ are generated and overwritten by the crawler, so contribute through the submit form or issues/PRs against crawler/.
