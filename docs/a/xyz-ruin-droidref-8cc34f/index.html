DroidRef

صوت وفيديو وموسيقى

DroidRef is an image reference board app for Android, like PureRef or VizRef . It lets you keep track of a large amount of reference images on an infinite canvas you can pan and zoom. You can crop out only the parts of each image you want to focus on and send pictures from any app that has an image
