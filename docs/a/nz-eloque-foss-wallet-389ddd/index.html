FossWallet

قراءة وكتابة

FossWallet is a simple Material Design 3 Passbook (.pkpass) Wallet built with Jetpack Compose. It shows the Barcode and the other data contained in the pass. The app supports updating passes from vendor servers for supported passes, but can otherwise be used fully offline.
