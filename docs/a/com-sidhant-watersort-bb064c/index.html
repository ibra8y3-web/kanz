Water Sort

ألعاب

Water Sort is a simple yet addictive puzzle game where you sort colored water in tubes until each tube contains only one color. How to play: - Tap a tube to pick up the top color, then tap another tube to pour it. - You can only pour the same color on top of another same color. - Sort all the tubes
