Euphony

صوت وفيديو وموسيقى

Euphony is an open-source music streaming client for Android, built with Flutter. Music is streamed from YouTube Music via the youtube_explode_dart library (InnerTube API). Lyrics are provided by LRCLIB (lrclib.net) and displayed as plain text. Features: * Ad-free music streaming from YouTube Music
