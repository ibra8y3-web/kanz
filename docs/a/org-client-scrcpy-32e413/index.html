Scrcpy for Android is an Android port of Scrcpy . This application mirrors display and touch controls from a remote android device to android device. Scrcpy for Android uses ADB-Connect interface to connect to android device to be mirrored. The latter needs to have ADB-connect/ADB-wireless/ADB over
