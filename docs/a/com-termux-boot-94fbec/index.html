Termux:Boot

برمجة

This plugin for https://f-droid.org/packages/com.termux allows programs to be run at boot. Instructions: * Start the Termux:Boot app once by clicking on its launcher icon. * This allow the app to be run at boot. * Create the ~/.termux/boot/ directory. * Put scripts you want to execute inside the ~/.
