Extra Keyboard Layouts

أدوات النظام

Adds a few choices to the list of layouts to use when a physical keyboard is connected e.g. via OTG or Bluetooth. This app does not create an icon of its own when you install it, but simply adds some new layout options for physical keyboards. These options are usually located under System › Language
