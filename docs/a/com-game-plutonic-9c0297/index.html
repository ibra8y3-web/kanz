Plutonic

ألعاب

Plutonic is a suika-like / sputnika-like planet combiner with gravity-based physics. Drag and launch planets to combine them into larger celestial bodies. The game ends if a planet hits another planet, and goes out of the field for 2.5 seconds. Try to not touch with force (only collisions)! Features
