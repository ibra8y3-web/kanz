TailSocks

أمان وخصوصية

TailSocks is an unofficial client for Tailscale networks (tailnets). It runs the Tailscale daemon in userspace-networking mode and gives your apps the tailnet through local SOCKS5 and HTTP proxies, so it does not take Android's VPN slot and runs next to another VPN, firewall or ad blocker.
