Bagatur Chess Engine

ألعاب

This is the open source Bagatur Chess Engine with its own GUI (graphical user interface). It is not as strong as Stockfish, Komodo, AlphaZero or Leela Chess Zero, but is strong enough to beat a grandmaster. It has 16 strength levels. From level 5, it could show the search information.
