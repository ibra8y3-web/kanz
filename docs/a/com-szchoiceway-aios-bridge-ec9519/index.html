Alt Launcher

أدوات النظام

The Problem: Phoenix Radios Android tablet style radios do not allow for running apps on boot or fastboot. This app solves that problem. When the Phoenix Radio boots (or fast-boots), the Alt Launcher starts the apps it is configured to start. The primary purpose is to launch two apps in split screen
