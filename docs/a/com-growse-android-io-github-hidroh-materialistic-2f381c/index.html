Materialistic Nouveau is a material design Hacker News client for Android. It's a fork of https://github.com/hidroh/materialistic Features: - Browse the top, new, best, ask, show and jobs stories on Hacker News - Read and post comments - Search stories using Algolia Hacker News Search - Save stories
