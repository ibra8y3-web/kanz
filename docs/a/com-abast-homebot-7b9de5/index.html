HomeBot

أدوات النظام

HomeBot enables you to remap the home button long press on you smartphone. You can set the following: * Opening an app * Opening a web page * Toggling the flashlight * Opening the recent apps screen * Toggling brightness The app doesn't need root but has to be set as your Assistant app in Settings >
