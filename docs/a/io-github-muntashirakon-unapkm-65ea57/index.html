UnApkm - Convert APKM to APKS

أدوات النظام

Apk Mirror's APKM is an encrypted bundled app format which can only be installed using their own installer. UnApkm is a small utility software that converts an APKM to APKS which can be installed via an split apk installer that supports APKS format. Instructions: The app doesn't have any GUI. Goto y
