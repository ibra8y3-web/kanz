ClaviRom is an adaptation of HeliBoard - a privacy-conscious open-source keyboard, based on AOSP / OpenBoard - to Swiss minority languages Does not use internet permission, and thus is 100% offline. New features of ClaviRom: Spell check and next word proposals for Swiss Romansh languages Puter, Surm
