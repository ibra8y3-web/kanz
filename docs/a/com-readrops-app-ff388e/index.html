Readrops

Readrops is a multi-services RSS client for Android. Its name is composed of "Read" and "drops", where drops are articles in an ocean of news. Features : - Local RSS parsing (RSS1, RSS2, ATOM, JSONFeed) - External services: - FreshRSS - Nextcloud News - Fever API - Google Reader API - Multi-account
