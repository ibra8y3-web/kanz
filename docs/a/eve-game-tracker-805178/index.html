Eve Game Tracker

ألعاب

Eve Game Tracker is a tracker for card games. (It's a fancy table) You WILL make an issue on github to add YOUR favorite game to the Eve Game Tracker. Currently supported games: Skat, Poker, Durak, Gambio, Uno. You can add custom games in a very intuitive way. Features: * Stat View * Persistent play
