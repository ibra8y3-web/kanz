SubSonicSter

ألعاب

SubSonicSter is a Hitster-compatible card game app that uses SubSonic-compatible music servers for playback. Features: • QR code scanning for Hitster game cards • CSV-based song mapping for different card sets • SubSonic API integration for music search and streaming • Audio playback with buffering
