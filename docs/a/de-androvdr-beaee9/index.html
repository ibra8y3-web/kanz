AndroVDR

صوت وفيديو وموسيقى

AndroVDR is an Android application to control the Linux based VDR . Features: remote control views for channels, timer, recordings, EPG search in EPG (epgsearch plugin in VDR required) display channel logos (not included) adjustable text size 2 different layouts 1 additional, user definable, layout
