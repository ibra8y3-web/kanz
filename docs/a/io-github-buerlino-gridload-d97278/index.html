GridLoad

مال وتسوق

GridLoad tells you at a glance whether now is a good time to run household appliances like the washing machine, dishwasher or EV charger. It reads your tariff's dynamic electricity price, or the day-ahead market price, and shows one colour: Green, good time: electricity is cheap, run your appliances
