Caps to Ctrl adds a keyboard layout (English, US, qwerty) which changed "Caps Lock" to "Ctrl" for the physical keyboard. Instead of the menu key, you can use "Ctrl + ESC" The other keyboard layouts are added as "Japanese (EN)" or "ThumbCtrl (EN)" but these are for Japanese keyboard This software use
