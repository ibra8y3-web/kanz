RedTrigger

أدوات النظام

RedTrigger enables shoulder triggers (SAR capacitive sensors) on Nubia Red Magic phones system-wide, without needing Game Space. Nubia's game framework controls the shoulder trigger hardware and only activates them inside Game Space. The system also resets trigger settings every time you switch apps
