MatrixSolver

MatrixSolver is an educational application for solving linear algebraic equation (SLAE) systems. MatrixSolver allows the user to: familiarize yourself with the theoretical part (SLAE, system matrix, SLAE solution methods); consider examples of specific problem-solving; solve SLAE by Gauss, Gauss-Sei
