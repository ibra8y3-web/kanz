Notification Notes

قراءة وكتابة

Simple note taking that lets you display your notes as native notifications. The notes are displayed as persistent low priority notifications. Features: * Save your notes to note list * Show/hide note's notification with a switch in note list * Remove note by long pressing it in the note list
