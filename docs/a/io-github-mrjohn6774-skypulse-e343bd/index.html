SkyPulse

SkyPulse is an Android receiver for monitoring 1090 MHz Mode S and ADS-B traffic with an RTL-SDR. It decodes aircraft data on-device using the separate FLOSS marto.rtl_tcp_andro driver, displays aircraft on a map, and includes offline FIR and TRACON boundary data.
